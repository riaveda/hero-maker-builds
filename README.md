# 히어로 메이커 — 빌드 배포 자리

**안드로이드 APK 를 받는 곳이다.** 소스는 여기 없다(비공개 저장소).

## 받는 법

오른쪽 **Releases** 에서 최신 `.apk` 를 누른다. **폰 브라우저로 열면 바로 받힌다.**

    설치할 때   안드로이드가 「출처를 알 수 없는 앱」을 묻는다 — 브라우저에 대해 허용하면 된다
    서명        디버그 서명이다. 스토어 배포용이 아니다

## 지금 무엇이 들어 있나

**아직 게임이 아니다.** 쿼터뷰 화면이 서는지 보는 단계다 — 마을·주인공·몬스터·상인이
자리표시(색 도형)로 서 있고, 움직이지 않는다.

## 앱이 스스로 갱신한다

`latest.json` 이 **지금 최신 판**을 가리킨다. 앱은 켜질 때 이것을 읽어 자기 `versionCode`
와 견주고, 새 판이 있으면 받아서 설치 화면을 띄운다.

**릴리스를 올릴 때 이 파일도 같이 고친다** — 안 고치면 앱이 옛 판을 최신이라 믿는다.
